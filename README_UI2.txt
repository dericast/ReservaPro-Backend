ReservaPro UI 2.0 listo

Archivos principales modificados:
- index.html: solo clase rp-ui2-dashboard si aplica.
- styles.css: diseño visual Google Calendar + Calendly.
- app.js: bloque seguro que reorganiza el dashboard sin cambiar IDs ni funciones.

Uso:
1. Haz copia de tu carpeta actual.
2. Copia estos archivos dentro de tu carpeta reserva-pro-v1.
3. Reemplaza app.js, index.html y styles.css.
4. Ejecuta npm start.
5. Abre la app y prueba login admin/empleado y link público.

Nota: no eliminé funciones; paneles secundarios se ocultan visualmente con CSS para acercar el dashboard al diseño, pero siguen presentes en el DOM.
